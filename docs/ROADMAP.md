# 开发路线图

## M0：基础工程（当前提交）

- [x] GitHub 仓库、MIT、双语 README
- [x] Go + Gin 后端入口与健康检查
- [x] Vue 3 + TypeScript + Vite 初始页面
- [x] Docker Compose 开发启动配置
- [x] 基本 Go 测试与 CI 构建流程
- [ ] 通过远程 CI 验证并固化前后端依赖锁文件

## M1：订阅与资源 V1

- [ ] 数据库选型落地（SQLite）、迁移脚本
- [ ] 分类与标签
- [ ] 订阅 / VPS / 域名等资源的 CRUD
- [ ] 月付、季付、年付、自定义周期
- [ ] 时区、月末、闰年边界测试
- [ ] 订阅状态（试用、活跃、暂停、取消）
- [ ] 服务端字段校验、分页与统一错误码
- [ ] 登录与用户数据隔离

**验收标准：** 重启服务后数据保留，至少一条订阅可创建、查看、编辑、取消，计费日期计算通过边界测试。

## M2：支付与提醒

- [ ] 实际支付流水与预测支出分离
- [ ] 收支统计及临期提示
- [ ] 提醒任务幂等、重试、发送日志
- [ ] SMTP 通知
- [ ] Telegram、Bark、Webhook 适配器
- [ ] 管理端通知测试及时间配置

**验收标准：** 可对不同订阅配置提醒；相同规则在同一触发日不会产生重复通知。

## M3：自部署正式版

- [ ] 数据备份恢复与迁移演练
- [ ] 生产 Docker 镜像与健康检查
- [ ] HTTPS 反向代理示例
- [ ] 跨版本数据库升级验证
- [ ] 安全检查、操作审计和依赖审计
- [ ] 端到端测试、正式发行版

## M4：可选高级功能

- [ ] 多币种与汇率历史
- [ ] CSV / JSON 导入导出
- [ ] AI 账单识别和自然语言录入
- [ ] MCP（基于授权的只读 / 写入能力）
- [ ] 多用户、家庭分摊

> 暂不追求全部功能同时上线。优先保证计费正确、提醒可靠、操作简单。
