# 开发路线图

## M0：基础工程（已完成）

- [x] GitHub 仓库、MIT、双语 README
- [x] Go + Gin 后端
- [x] Vue 3 + TypeScript + Vite
- [x] Docker Compose
- [x] GitHub Actions Go/Vue 构建

## M1：订阅与资源 V1（进行中）

- [x] SQLite 初始 Schema、版本标记及持久化
- [x] 分类 CRUD
- [x] 订阅/资源 CRUD
- [x] 月付、按日、按年、自定义周期及一次性到期
- [x] 时区设置与月末、闰年边界单元测试
- [x] 状态（正常、暂停、取消）
- [x] 服务端校验、分页、中文错误提示
- [ ] 登录与用户数据隔离
- [ ] 数据迁移升级策略
- [ ] 前端端到端测试、可访问性检查与分页

**验收：** 数据在程序重启后保持；可添加、编辑、删除、查询项目；周期计算包含月底和闰年边界。当前版本仅适合可信的本地环境。

## M2：付款与提醒

- [ ] 预计支出与真实支付流水分离
- [ ] 财务看板、费用趋势和汇率
- [ ] 提醒规则、幂等键、失败重试、日志
- [ ] SMTP、Telegram、Bark、Webhook 通知

## M3：正式自部署版本

- [ ] 安全认证及访问权限
- [ ] 生产部署 Docker 镜像（非开发 Vite 服务）
- [ ] 数据库备份、恢复、迁移演练
- [ ] 反向代理 HTTPS、速率限制及安全响应头
- [ ] 端到端测试与正式版发布

## M4：可选高级功能

- [ ] AI 账单识别
- [ ] MCP
- [ ] CSV / JSON 迁移
