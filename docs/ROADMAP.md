# 开发路线图

## M0：基础工程（已完成）

- [x] GitHub 仓库、MIT、双语 README
- [x] Go + Gin 后端
- [x] Vue 3 + TypeScript + Vite
- [x] Docker Compose
- [x] GitHub Actions Go/Vue 构建

## M1：订阅与资源 V1（进行中）

- [x] SQLite 初始 Schema、版本标记及持久化
- [x] 分类 CRUD
- [x] 订阅/资源 CRUD
- [x] 月付、按日、按年、自定义周期及一次性到期
- [x] 时区设置与月末、闰年边界单元测试
- [x] 状态（正常、暂停、取消）
- [x] 服务端校验、分页、中文错误提示
- [x] 单管理员登录与 API 鉴权
- [ ] 多用户数据隔离
- [x] V3 增量迁移（管理员凭证与会话）
- [ ] 版本升级回滚演练
- [ ] 前端端到端测试、可访问性检查与分页

**验收：** 数据在程序重启后保持；可添加、编辑、删除、查询项目；周期计算包含月底和闰年边界。当前版本仅适合可信的本地环境。

## M2：付款与提醒

- [x] 预计支出与真实支付流水分离
- [x] 按币种独立统计月度实付金额和六个月趋势
- [ ] 汇率换算和预算分析
- [x] 提醒规则、站内通知、幂等去重
- [x] 外部渠道持久化发送日志与退避重试（最多 4 次）
- [x] SMTP、Telegram、Bark 通知适配器
- [ ] Webhook 与通知测试功能

## M3：正式自部署版本

- [x] 单管理员身份认证、会话和基础 CSRF 保护
- [ ] 更完善的访问控制、密码恢复与登录审计
- [x] 独立生产 Compose、Caddy HTTPS 与 Vue 静态镜像
- [x] SQLite 快照备份和最近 7 份自动轮换
- [x] Restic 加密异地备份配置、脚本与 CI 本地仓库演练
- [ ] 生产异地恢复演练和一键恢复
- [x] HTTPS 反向代理、Secure Cookie、安全响应头和 API 容器内网化
- [ ] 更细粒度限流与公网安全测试
- [ ] 端到端测试与正式版发布

## M4：可选高级功能

- [ ] AI 账单识别
- [ ] MCP
- [ ] CSV / JSON 迁移
- [ ] 多用户与家庭账本
